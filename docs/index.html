01 / The toolkit

Start simple.
Let the data bend.

Follow a sequence of models, from a single straight trend to flexible curves and additive effects you can inspect.

01 — BASELINES

Polynomials & steps

Compare smooth global curves with piecewise-constant age groups, then use cross-validation to guide complexity.

02 — FLEXIBLE CURVES

Regression splines

Join local polynomial pieces into a continuous curve and examine how each model behaves beyond the data.

03 — CONTROL THE SHAPE

Smoothing & local fits

Balance flexibility against roughness with a penalty, then compare it with a neighborhood-based smoother.

04 — PUT IT TOGETHER

Generalized additive models

Give age and year their own curves, account for education, and inspect each feature’s partial effect.

05 — A SECOND QUESTION

Logistic GAM

Model the probability of earning above the project’s high-earner threshold with the same additive structure.

06 — CHECK THE FIT

Test-set comparison

Compare held-out prediction errors after choosing settings on the training data.

02 / Try it yourself

Run the walkthrough.

Clone the repository, install its Python packages, and run the script. The first run downloads the ISLP Wage data, so it needs an internet connection.

TERMINAL 
# Get the project
$ git clone https://github.com/aditya00801/beyond-linearity-splines-and-gams-with-scikit-learn.git
$ cd beyond-linearity-splines-and-gams-with-scikit-learn

# Install and run
$ python -m pip install -r requirements.txt
$ python scaffold.py

Want to check the examples? Run python -m unittest discover -s tests.
